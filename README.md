# Звёздный сад

Звёздная система, по которой можно летать прямо в браузере: солнце с короной, газовый гигант с кольцами и поясом астероидов, планета с океанами, облаками и огнями городов, луна в кратерах и орбитальная станция.

Всё создаётся кодом: никаких картинок, 3D-моделей и звуковых файлов. Вся сцена помещается в один файл `index.html` (~70 КБ, без минификации). Идея взята у [Abyssal Garden](https://github.com/Noniv/abyssal-garden).

## Как запустить

1. Открой `index.html` в Chrome или Edge на компьютере (двойной щелчок по файлу).
2. Подожди пару секунд и нажми «Полетели».

Ничего устанавливать не нужно, работает офлайн. Нужен браузер с WebGPU.

## Управление

| Действие | Клавиши |
|---|---|
| Осмотреться | мышь (если указатель не захватился — зажми кнопку мыши и води) |
| Лететь | W A S D |
| Вверх / вниз | E / Q |
| Ускорение | Shift (растёт, пока держишь) |
| Точки обзора | 1–6 |
| Звук | M |
| Статистика | H |
| Меню | Esc |

## Как это устроено

- **Небо** — полноэкранный шейдер: туманности из фрактального шума (fbm), Млечный Путь, три слоя процедурных звёзд.
- **Солнце** — сфера с «кипящей» грануляцией и корона-билборд с лучами.
- **Газовый гигант** — полосы из искажённого шумом синуса, шторм-вихрь, тень колец на планете.
- **Кольца** — один квадрат, плотность по радиусу (щель Кассини), тень планеты на кольцах.
- **Планета** — материки, океаны с бликом, облака, полярные шапки, огни городов на ночной стороне, рельеф через экранные производные.
- **Луна** — кратеры из ячеистого шума.
- **Пояс астероидов** — до 28 000 камней (4 формы, инстансинг), каждый вращается и летит по своей орбите.
- **Станция** — тор, ступица, спицы и солнечные панели, построены из простых фигур.
- **Пыль** вокруг камеры растягивается в штрихи на скорости.
- **Постобработка** — HDR, свечение (bloom) в трёх масштабах, ACES-тонмаппинг, виньетка.
- **Звук** синтезируется на лету через Web Audio API.
- Буфер глубины с обратным Z, поэтому одинаково точно рисуются и камни в метре от камеры, и планеты в тысячах единиц.
- Если кадр рисуется дольше ~19 мс, разрешение понижается само.

## Где что менять

Всё в `index.html`:

- `SUN_R`, `GIANT`, `EARTH`, `MOON` — размеры и положения тел.
- `QUALITY` — сколько астероидов и пыли на каждой детализации.
- `VIEWS` — шесть точек обзора.
- `SKY_WGSL` — звёзды и туманности, `PLANET_WGSL` — солнце и планеты, `RING_WGSL` — кольца.
- Скорость полёта: ищи `22 + 1400` в `frame()`.

## Для разработки

- `index.html?q=low` — принудительно задать детализацию.
- `index.html?offscreen#view3` — рендер без холста, сразу с точки обзора 3 (так делались автоматические скриншоты в headless Chrome).
